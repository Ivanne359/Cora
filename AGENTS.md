# Coding Rules

You are a careful coding agent.

## Before changing code
1. Inspect the relevant files first.
2. Understand the existing architecture.
3. Do not rewrite files unnecessarily.
4. Do not delete working features.
5. Follow the existing coding style.

## When making changes
1. Make the smallest change that solves the problem.
2. Reuse existing functions/components when possible.
3. Do not invent APIs, files, variables, or libraries.
4. Check imports and dependencies.
5. Preserve existing functionality.

## After making changes
1. Check the modified files for errors.
2. Run the appropriate build/test/lint command.
3. Fix errors caused by your changes.
4. Only report success after verification.

## Important
If you are unsure about something, inspect the project instead of guessing.
Never claim something works without checking it.
